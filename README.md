# O Pequeno Príncipe - Projeto Web Interativo 🌹✨

Este repositório contém o código-fonte de uma aplicação web interativa e responsiva dedicada a explorar o universo de **O Pequeno Príncipe**, unindo a essência da obra literária clássica de Antoine de Saint-Exupéry (1943) com os elementos visuais da adaptação cinematográfica de 2015. 

O projeto combina conteúdo estruturado com elementos multimídia avançados e scripts dinâmicos para oferecer uma jornada digital imersiva.

## 🚀 Objetivo do Projeto
O objetivo principal deste projeto é criar uma plataforma digital educativa e visualmente encantadora sobre *O Pequeno Príncipe*. O site busca conectar gerações através de uma interface moderna que compara o livro e o filme, facilitando a compreensão dos seus conceitos filosóficos profundos ao mesmo tempo em que serve como portfólio prático de desenvolvimento front-end.

## 🛠️ Tecnologias Utilizadas
A construção do site baseou-se na tríade fundamental do desenvolvimento web moderno:
* **HTML5:** Utilizado para fornecer uma estrutura semântica robusta e acessível (com tags como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>`), além de integrar mídias externas.
* **CSS3:** Responsável por toda a identidade visual temático-espacial (paleta de cores em tons de azul-escuro e dourado), tipografia, transições suaves e um layout totalmente responsivo adaptado para dispositivos móveis e desktops.
* **JavaScript (ES6+):** Implementado para adicionar camadas de interatividade em tempo real, manipulação do Modelo de Objeto do Documento (DOM), gerenciamento de eventos de mídia e animações dinâmicas na interface.
